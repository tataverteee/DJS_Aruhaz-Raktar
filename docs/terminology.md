# Terminológia

| Fogalom | Meghatározás |
|---|---|
| **(Áru)kiadás** | A raktárkészletből a megrendelt mennyiséget a megrendelt termékből kitörölni. |
| **Rendelés** | A raktárba befolyó termékek megrendelése. |
| **(Áru)átvétel** | A megrendelt áru rögzítése a raktárba. |
| **Vendég profil** | Az eladótérben dolgozó nem raktáros felhasználó. |
| **Raktáros profil** | A raktárban dolgozó anyagmozgatással foglalkozó felhasználó. |
| **Admin profil** | A felhasználókat felügyelő, minden joggal rendelkező felhasználó. |
